# Turing App Web

React, TypeScript ve Vite tabanlı frontend uygulaması.

## Gereksinimler

- Node.js 20+
- npm 10+

## Kurulum ve çalıştırma

```bash
npm install
npm run dev
```

Uygulama varsayılan olarak `http://localhost:5173` adresinde açılır.

## Doğrulama

```bash
npm test
npm run lint
npm run build
```
